# Presentation Helper Examples

This directory contains example templates and generated presentations demonstrating the presentation-helper skill capabilities.

## 📁 Directory Structure

```
examples/
├── templates/          # Reference PowerPoint templates
│   └── [your-branded-template.pptx]    # User-provided brand template
└── outputs/           # Generated presentations
    └── [Claude_Skills_Presentation.pptx] # Sample output
```

## 🎨 Templates

### Corporate Brand Template
- **File**: `[your-branded-template.pptx]` (user-provided template)
- **Brand**: Your organization's corporate branding
- **Features**: 
  - Custom brand color scheme
  - Corporate typography and fonts
  - Professional corporate layouts
  - Integrated logos and footer elements

## 📊 Sample Outputs

### Claude Skills for Product Managers
- **File**: `Claude_Skills_for_Product_Managers.pptx`
- **Content**: 13-slide presentation about AI skills
- **Demonstrates**: 
  - Brand consistency with corporate styling
  - Smart content generation
  - Professional slide structure
  - Proper placeholder handling

## 🔄 Usage

1. Use any template from the `templates/` directory as your reference
2. Run the presentation-helper skill with your content requirements
3. Generated presentations will match the template's branding automatically

## 📝 Template Requirements

For best results, reference templates should have:
- Multiple slide layouts (title, content, section dividers)
- Consistent color scheme and fonts
- Proper master slide configuration
- Clear placeholder structure

## 🎯 Quality Standards

All example outputs demonstrate:
- ✅ Complete content in all placeholders
- ✅ Brand-consistent colors and fonts  
- ✅ Professional layout structure
- ✅ No broken or empty elements
- ✅ Ready for executive presentation
